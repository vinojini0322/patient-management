# Patient Management System

## A full-stack web application to manage patient records efficiently.

## Features

- Add, update, delete patients
- View patient list in table format
- Responsive UI with modal forms
- Clean and simple dashboard design.

---

## Tech Stack

### Frontend

- React.js
- Bootstrap / CSS

### Backend

- Java
- Spring Boot
- REST APIs

### Database

- PostgreSQL

---

## Project Structure

patient-management/
│
├── patient/ # Backend (Spring Boot)
├── patient-frontend/ # Frontend (React)
└── README.md

---

## Setup Instructions

### 1. Clone the repository

## git clone https://github.com/vinojini0322/patient-management.git

### 2. Run Backend

cd patient
./mvnw spring-boot:run

---

### 3. Run Frontend

cd patient-frontend
npm install
npm run dev
